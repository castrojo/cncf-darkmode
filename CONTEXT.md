# CNCF Unified Site

One unified Astro project serving multiple sections of the CNCF landscape (Projects, End Users, and People) under a single host domain and build system.

## Language

**Section**:
A primary functional and navigational area of the unified site, specifically Projects, End Users, or People.
_Avoid_: Website, sub-site, separate website, application, app

**Member**:
An organization that is part of the CNCF.
_Avoid_: Client, buyer, partner, subscriber, sponsor

**End User**:
A specific category of Member that consumes cloud-native technologies internally rather than selling them as commercial products or services.
_Avoid_: Customer, user, client, consumer

**Contributor**:
An individual community member who participates in or leads CNCF initiatives, projects, or committees.
_Avoid_: Person, user, account, member, individual

**Activity**:
A record of a specific community event or update (such as a joining date, role modification, or emeritus status change) displayed chronologically.
_Avoid_: Timeline card, log entry, profile item, event

**Maturity**:
The official graduation stage of a CNCF project (Graduated, Incubating, or Sandbox).
_Avoid_: Tier, stage, status, state, phase, level

**Graceful Degradation**:
The build-time fallback mechanism that allows Astro pages to compile successfully with placeholder or empty state elements if the required data files (generated by Go sync) are missing.
_Avoid_: Offline support, offline mode, fallback rendering, build resilience

**Sync Pipeline**:
The Go-based automation programs that pull, normalize, and enrich data from upstream CNCF repositories and APIs to generate static JSON datasets for the unified site.
_Avoid_: Update worker, cron job, crawler, loader, data grabber, ingestion pipeline

**Theme System**:
The JS/CSS architecture that implements dark and light mode, reading user preferences from local storage or system defaults, and applying a theme attribute to the HTML element while preventing rendering flashes.
_Avoid_: Dark mode, custom theme wrapper, style selector, display mode switcher, skin manager
